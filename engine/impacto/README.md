# Private Impacto runtime

This directory describes the pinned upstream engine embedded by Tyranor. It is not a new implementation of the engine. The Android host and launcher live in their normal engine/app modules; existing SDL2 and SDL3 runtimes are unchanged.

## Rebuild

Run from the Tyranor repository root on Linux with Git, Python 3, C/C++, make, Ninja, pkg-config, Perl, autoconf, automake, libtool, m4, NASM, Bison, Flex and a supported CMake. Use Android NDK 28.0.13004108 and CMake 3.31.1 or later. The upstream minimum is CMake 3.28. The dependency manager can download its own pinned CMake for ports; that version is recorded separately from the top-level CMake.

```sh
export ANDROID_NDK_HOME=/path/to/ndk/28.0.13004108
export IMPACTO_CMAKE=/path/to/cmake/3.31.1/bin/cmake
export IMPACTO_BUILD_ROOT=/path/to/isolated/impacto-build
export VCPKG_MAX_CONCURRENCY=4
tools/impacto/build-native.sh
python3 tools/impacto/test-native-adapter.py --source "$IMPACTO_BUILD_ROOT/source"
```

Ninja is resolved from `IMPACTO_NINJA` when set, otherwise from an executable next to the resolved CMake, and finally from `PATH`. An invalid explicit override fails clearly instead of silently selecting another tool. `tools/impacto/test-build-tools.sh` checks this resolution without running a build.

The recipe verifies immutable Git revisions from source-lock.json, fetches vcpkg history needed for versioned ports, and applies the checked-in native patch and private SDL overlay. Its binary cache is workspace-local. Do not place the build root inside a user game directory. Network access to the documented upstream sources is needed for a first online build. Corresponding-source archives and their separate reproduction instructions are described in SOURCE-DISTRIBUTION.md.

The Android shared library uses ARM64, API 28, static libc++, PIC, and 16 KiB ELF LOAD alignment. This does not raise the minimum API of other Tyranor engines. The entire upstream codec/profile implementation is retained. The build does not enable FFmpeg GPL, version3 or nonfree features.

`tools/impacto/package-runtime.py` produces resources.zip.xz, its manifest, libimpacto.so and runtime-provenance.json. The outer XZ stream contains ZIP_STORED entries with deterministic order, timestamps and permissions. Every resource is hashed. Resource inputs must exactly match tracked files at the pinned upstream revision. Profile IDs and entry-point hashes are in profiles.json; the Java projection is generated by generate-profiles-java.py. No user-owned game data is bundled.

## Isolation and launch contract

Private Java SDL classes are in org.libsdl.impacto and private native JNI prefixes are org_libsdl_impacto. SDL 3.4.10 has no general SDL_ANDROID_JAVA_PACKAGE CMake option: the patch covers both JNI prefix definitions, all five native Java class registration strings (including HID), and the Java package/action references. The Java source version and the native version must agree. The source patch also makes failed loads safe in early lifecycle callbacks and exposes localized error-dialog hooks to the host.

The native adapter requires `--tyranor-resource-root`, `-bp`, `-gc`, `-uc`, and `-g`. The host must pass individual argument strings, never shell commands. The resource root must be the host-validated immutable private resource generation, not a game folder. Basepaths and gamedefinitions must be readable regular absolute files generated by the host. Native code repeats fail-closed existence checks immediately before configuration selection and never falls back to upstream files when a required launch path is missing. The host also validates private containment, selected profile, generation identity, game roots, and save paths.

The standalone upstream directory-picker callbacks are disabled in host mode. ImGui relative ini/log writes are also disabled; persistent user settings and optional file logs use the host-provided TOML. An out-of-line FSFolderArchive destructor supplies the complete vector element type required by NDK28 libc++. Private Bluetooth operations handle revoked permissions; receiver exports and API29 calls are explicitly bounded.

`test-native-adapter.py` checks the closed native argument/path boundary on the build machine. `test-patch-boundary.py` compiles the actual patch-selection function in host and upstream modes and verifies that host mode ignores stale patch settings without mutating them. Unsupported standalone patch controls and patch CLI options are unavailable in host mode. It does not run Android JNI, render a frame, or validate any game. The resource manifest, ELF report, generated Java metadata and provenance are review inputs, not evidence of gameplay compatibility.

## Resources and notices

The retained profiles, shaders and resources are pinned, unmodified tracked upstream files. Upstream LICENSE and README state ISC scope, and THIRDPARTY identifies exceptions. We preserve those notices and the full SIL OFL for the bundled Noto fonts. The original authorship/license provenance of individual game-style atlas images has not been independently verified; this statement is not a claim of separate rights clearance. No affirmative upstream exclusion was found during the bounded review. Any later conflicting evidence must be resolved before continued distribution.

Actual dependency notices are under licenses/dependencies. In particular, the bundled mspack headers identify LGPL 2.1 even though the upstream aggregated notice reproduces LGPL 2.0; the correct 2.1 text accompanies the source. FFmpeg 7.1.2 is built in its LGPL configuration. Static linking requires retaining the corresponding-source/relink materials, not just these notices or download links. Do not publish a library alone or invent a written source offer. See SOURCE-DISTRIBUTION.md and the generated source index.

## Remaining release gates

- Real ARM64 Android launch/playback, audio/input and lifecycle tests with legally obtained game assets.
- API 28 boundary and 16 KiB-page device checks. ELF alignment alone is insufficient.
- Persistent saves/settings, two-game separation, back/kill/relaunch and process failure behavior.

Minified Release JNI/R8 and Debug/Release APK packaging checks passed with 51 private SDL classes and all 67 JNI methods retained. The current source bundle and source-modified mspack replacement/relink smoke have passed the static checks recorded in runtime-provenance.json and relink-report.json. This is not a fresh offline rebuild or a device execution test. See the [integration acceptance record](../../docs/impacto-acceptance.md) for the consolidated status; completed build-time checks must not be treated as gameplay validation.

All eight exposed profiles remain experimental and unverified until those checks are recorded. Hidden upstream entries retain that classification in metadata.
