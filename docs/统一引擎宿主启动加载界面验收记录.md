## 3. 设备与运行方式

- 设备：MAA-AN10，Android 16 / API 36，arm64-v8a。
- 隔离目标：`com.tyranor.next.startuptest`，仪器包为其 `.test` 包。
- 显式 opt-in：`startup_test=true`；测试拒绝在正式包运行。
- 原创夹具位于独立包私有 files / cache；未使用正式安装的游戏库或存档。
- 证据导出后已卸载本轮创建的隔离目标和仪器包；正式安装未替换，正式默认包名 Debug APK 已构建。
- 最后一轮完整仪器测试结果：**OK (9 tests)**，约 36.26 秒。

```bash
TYRANOR_APPLICATION_ID=com.tyranor.next.startuptest ./gradlew \
  :engine:testDebugUnitTest :engine:jsHarness \
  :app:assembleDebug :app:assembleDebugAndroidTest

# 先核对 output-metadata.json 中两个 applicationId，再安装。
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -r \
  -e class com.core.engine.EngineStartupDeviceTest,com.core.engine.EngineStartupWebDeviceTest,com.core.ethornell.EthornellStartupActivityTest \
  -e startup_test true \
  com.tyranor.next.startuptest.test/androidx.test.runner.AndroidJUnitRunner
```

Gradle 构建串行运行，避免压缩资产临时文件竞争。仪器运行时不同时启动 CLI 无障碍服务。

## 4. 已通过的九项设备回归

1. 加载遮罩消费触摸；失败后的迟到 reveal 无效；dispose 后不再拦截内容。
2. 应用内 TYPE_APPLICATION_PANEL 不抢主窗口焦点，宿主 AlertDialog 的确认按钮可实际点击；移除不泄漏窗口。
3. stop 后的探针不接受就绪，恢复后只触发一次成功。
4. 不透明遮罩存在时，Framebuffer 有效黑 Bitmap 的 onDraw 通知仍能到达。
5. 无 queued buffer 时不提前揭层；提交合法黑 buffer 后 PixelCopy 能结束等待，遮罩本身不能被当作源帧。
6. 独立 RPG Maker MV v1 宿主：原创页面呈现、子资源 404 不失败、实际 reload 后不重新显示启动遮罩。
7. Tyrano WebOther 私有宿主：同样验证页面与实际 reload。
8. 边界组合：Tyrano 空 HTML 可退场；RPG 被拦截初始 scheme 及主框架 HTTP 404 稳定保持失败态，迟到视觉 callback 不揭开错误。
9. Ethornell 真实私有宿主：生产 dispatch / 私有数据目录、真实 native 色块、加载标题退场、前台宿主、正常退出与终态 ACK。

WebView 在本机重载后存在虚拟无障碍树缓存滞后：截图已显示第二次内容，节点树却可能丢失其子节点。因此重载断言采用原创页面的红→绿大色块与实际截图采样，原生加载 / 失败标题仍通过无障碍树检查。这仅用于测试视觉证明；产品没有通过截图颜色猜测游戏就绪。
