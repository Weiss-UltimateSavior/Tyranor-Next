# 高级玻璃外观风格计划方案（含「玻璃 → 复古玻璃」更名）

> 目标：在「应用设置 → 外观风格」新增第三档「高级玻璃」——**复刻参考图（系统通知栏）的材质**：
> 真实图片的重度模糊底 + 浅色磨砂卡片（上亮下暗描边、顶边高光）+ 悬浮玻璃按钮；
> 与现有玻璃风格并存；同时把现有「玻璃」的**显示名**更改为「复古玻璃」。
> 切换即时生效、重启保持；默认与复古玻璃的既有视觉零回归（复古绘制代码不改）。
>
> **v2 修订**：初版把高级玻璃做成复古玻璃的换色版（合成色斑背景 + 深色膜），不是复刻。
> 本版改为独立实现：背景用游戏封面拼贴后做多轮盒式模糊（真实图片模糊），
> 卡片用浅色磨砂膜，详见 §6.3；复古玻璃的 `GlassStyle.kt` 已还原为改动前实现。

## 1. 决策记录（建议值，待确认项见 §15）

| 决策点 | 结论 |
|---|---|
| 显示名 | 外观风格三档：**默认 / 复古玻璃 / 高级玻璃** |
| 存储值 | `default` / `glass`（语义改为复古玻璃，**值不变、存量零迁移**）/ `glass_advanced`（新增） |

| 复用策略 | 复用行为层（动态色 getter 分发 / `glassBorder` 转发 / scheme 映射 / 禁用规则 / 32dp 形状），不复用复古的绘制实现 |

## 3. 图片材质拆解 → 本项目映射

图中（通知栏样式）只有三层，且**模糊只做了一次**：

| 层 | 图中现象 | 本项目对应实现 |
|---|---|---|
| ① 全局底 | 整屏重度模糊的真实图片 + 深色压暗 + 四角暗角 | `AmbientBackdrop`：游戏封面拼 2×3 小图 → `boxBlurArgb` 多轮模糊 → `advancedGlassPageBackground` cover 铺满 + 黑 48% + 暗角；无封面时退化主题色软色斑 |
| ② 半透表面 | 大圆角卡片/按钮：浅色通透膜，卡后模糊与周围一致 | 浅色磨砂膜 `AdvancedGlassSurface`（14% 白）+ 上亮下暗渐变描边（20%→5% 白）+ 顶边高光；悬浮导航条叠加真 backdrop 采样（API 31+） |
| ③ 光学装饰 | 顶边亮线、按钮边缘高光、极淡投影 | `advancedGlassBorder`（渐变 brush 描边）+ `glassSpecular`（顶边高光条）+ `Highlight`/`Shadow`（复用 backdrop 库） |

**关键结论**：图中卡片自身不跑模糊管线——背景已全局模糊，卡片只是浅色半透膜。
真按「每卡片各自 blur 背后」实现会有 N 条 `RenderEffect` 管线且模糊度随位置漂移，故本项目不做。

## 5. 设置模型

### 5.1 新增 `core/settings/AppearanceStyle.kt`（纯 Kotlin，可 JVM 单测）

```kotlin
enum class AppearanceStyle(val storageValue: String) {
    DEFAULT("default"),
    RETRO_GLASS("glass"),            // 原「玻璃」：值保持不变，存量用户零迁移
    ADVANCED_GLASS("glass_advanced"); // 新增「高级玻璃」

    val isGlass: Boolean get() = this != DEFAULT
    val isAdvancedGlass: Boolean get() = this == ADVANCED_GLASS

    companion object {
        fun fromStorage(value: String?): AppearanceStyle =
            entries.firstOrNull { it.storageValue == value } ?: DEFAULT
    }
}
```

`AppSettingsStore`：删除 `APPEARANCE_STYLE_DEFAULT/GLASS` 两常量（或改为 `AppearanceStyle` 的别名），
枚举持有三档持久化取值（`default` / `glass` / `glass_advanced`，常量并入枚举，`AppSettingsStore` 不再单独定义）；get/set 改收发枚举：

```kotlin
fun getAppearanceStyle(c: Context): AppearanceStyle =
    AppearanceStyle.fromStorage(prefs(c).getString(KEY_APPEARANCE_STYLE, null))
fun setAppearanceStyle(c: Context, style: AppearanceStyle) =
    prefs(c).edit().putString(KEY_APPEARANCE_STYLE, style.storageValue).apply()
```

调用点仅 3 处，改动可控：`AppThemeColors.kt:50`、`AppScreen.kt:33`、`AppSettingsActivity.kt:164-177`。

### 5.2 `theme/AppThemeColors.kt`

```kotlin

    toneSwitchEnabled = !appearanceStyle.isGlass && AppSettingsStore.isToneSwitchEnabled(context)
    // ThemeColorPayload：高级玻璃 cardArgb 用 AdvancedGlassSurfaceSolid（网页壳不支持磨砂膜，取不透明合成色）
}
```

- `isGlass` 语义从「仅复古玻璃」扩为「任意玻璃档」是**有意设计**：让高级玻璃自动继承全部既有玻璃适配
  （透明页面背景、玻璃面、描边、禁用规则），避免逐个改 16 处 `isGlass` 调用点。
- 需逐一 review 的 `isGlass` 分支（共 16 文件）中，凡硬编码 `Glass*` 色值的（`Color.kt`、`GlassStyle.kt`、
  `GlassNavigationThemeAdapter.kt`、`MiuixSettingsTheme.kt`）补高级分支；纯行为分支（`AppShapes.kt`、
  `MainScreen.kt:142`、系统栏判定）无需改动。

### 5.3 生效规则（与复古玻璃一致）

- 高级玻璃恒深色、禁用「外观模式」与「色调切换」、**色调轮盘保持可用**（兜底色斑随主题色变化）。
- 切回默认/复古后，被禁用的存储值照常恢复生效。

## 6. 视觉体系

### 6.1 色板（`theme/Color.kt` 新增，浅色磨砂体系）

| 常量 | 值 | 用途 |
|---|---|---|
| `AdvancedGlassSurface` | `0x24FFFFFF` | 主卡片/条目：14% 白磨砂膜（参考图的浅色玻璃卡；过高会发白） |
| `AdvancedGlassSurfaceHigh` | `0x2EFFFFFF` | 输入框/弹窗内条目/指示器：18% 白 |
| `AdvancedGlassSurfaceSolid` | `0xFF2A2D33` | 无实时模糊降级路径用的不透明玻璃面（液态玻璃底栏 fallback） |
| `AdvancedGlassNavSurface` | `0x24FFFFFF` | 悬浮导航条底（14% 白 + 真采样 + 高光 + 投影） |
| `AdvancedGlassBorder` | `0x33FFFFFF` | 描边上端 20% 白 |
| `AdvancedGlassBorderFaint` | `0x0DFFFFFF` | 描边下端 5% 白（上亮下暗） |
| `AdvancedGlassSpecular` | `0x1FFFFFFF` | 顶边高光条 12% 白，向下渐隐 |
| `AdvancedGlassTextSecondary` | `0xFFC7CBD2` | 次要文字（比复古的 `GlassTextSecondary` 更亮，浅膜上可读） |
| `AdvancedGlassUnselected` | `0xFFB6BBC3` | 未选中图标/文字（浅色玻璃条上的未选中态） |
| `AdvancedGlassBgTop/Mid/Bottom` | `0xFF1B1D22 / 0xFF101216 / 0xFF07080A` | 兜底背景（无封面库）底色渐变 |

文字沿用 `GlassText/GlassTextSecondary`，不新增。

弹窗/抽屉面板不使用固定色：由 `rememberAdvancedGlassPanelSurface()` **从页面背景取色**生成竖向渐变
（把环境底图按高度三等分取平均色 → 向深色基底 `#121418` 压暗 0.72 → alpha 0.94）；
底图为空时用主题色 + 兜底背景色。弹窗/抽屉是独立 window，采不到主窗口 backdrop，本渐变即跨窗口替代。
**抽屉渐变必须画在内容层（LazyColumn 的 modifier）**：抽屉位置由内部 anchors 布局偏移决定，
挂在 Surface 外层 modifier 会落在未偏移位置（与玻璃描边同一个坑）；把手条用 `topColor` 续色无缝衔接。

### 6.3 封面拼贴模糊背景（独立实现）

- `ui/common/glass/AmbientBackdrop.kt`（新增）：
  - 取 `quickLaunch + recentGames + games` 中最多 6 个非空 `coverUri`（不足循环复用）；
  - 每张封面按瓦片尺寸 `inSampleSize` 解码 → 居中等比裁切画进 2×3 马赛克（288×432）；
  - `boxBlurArgb(radius = 10, passes = 3)` 多轮盒式模糊（复用 `ui/common/ImageBlur.kt`，全 API 一致）；
  - 结果 `ImageBitmap` 经 `AppThemeColors.updateAmbientBackdrop` 写入全局快照，单条缓存避免重复解码/模糊；
  - `rememberAmbientBackdrop(coverUris, enabled)` 在后台线程生成，`enabled = false`（非高级玻璃）时清空。
- `theme/AdvancedGlassStyle.kt` 的 `advancedGlassPageBackground`：底图 cover 缩放铺满 + 黑 48% 压暗
  + 暗角（中心 55% 半径内透明 → 边缘黑 35%）；无底图时退化为主题色三色软色斑 + 暗角。
- 底图只在封面集合变化时重建一次，绘制为一次 `drawImage`（`FilterQuality.Low`），零逐帧管线开销。
- 二级页（`AppScreenScaffold`）与主界面共用同一份快照底图；进程直接恢复到二级页时尚未生成，退化为兜底色斑。

### 6.4 表面与描边/高光（独立实现，复古代码不改）

组件玻璃统一为「与悬浮默认导航条同款」的光学组合：14% 白磨砂膜 + 渐变描边 + 顶边高光 + 柔光投影。

- `theme/AdvancedGlassStyle.kt`（新增）：
  - `advancedGlassBorder`：**加色受光内描边**（导航条 `Highlight.Default` 等价实现：45° 白色渐变、受光侧 30% → 背光侧 5%、
    `BlendMode.Plus`、描边 ×2 后裁剪到形状内只露内侧一半）+ 竖向渐变发丝描边
    （上 `AdvancedGlassBorder` → 下 `AdvancedGlassBorderFaint`）+ 顶边高光条
    （[AdvancedGlassSpecular] 向下 22% 高度渐隐）；由 `GlassStyle.glassBorder` 在高级档**一行转发**，
    约 33 处调用点零改动；复古分支代码保持原样；
  - `glassShadow`：与导航条 `Shadow.Default` 等价的柔光投影（BlurMaskFilter 画偏移轮廓 +
    even-odd 差集把形状内部挖空，半透明膜不会被投影压暗）；默认/复古 no-op；
    必须挂在组件**背景之前**（或 Card/MiuixCard 这类背景在内部的组件链上）；
  - `advancedGlassPageBackground`：见 §6.3。
- 挂投影的组件：全部 MiuixCard/Card 页面卡、快捷启动卡、游戏封面卡、封面搜索弹窗、
  统一弹窗、裁剪弹窗、搜索框胶囊、悬浮默认导航条降级路径；列表行（AppNavItem）不挂，避免列表发噪。
- 圆角沿用 `AppShapes.kt` 32dp，不开新豁免。

## 10. 降级、性能与边界

- **API 31+**：封面模糊底图 + 浅色磨砂膜 + 悬浮条真采样（`RenderEffect`）。
- **API < 31**：底图模糊不依赖 `RenderEffect`（盒式模糊，观感一致）、膜与描边完整；
  仅悬浮条退回浅色半透膜；不隐藏选项、不做 toast。
- **性能预算**：底图仅在封面集合变化时后台重建一次（288×432 解码 + 模糊，单条缓存）；
  绘制为一次 `drawImage` + 两次 `drawRect`；`glassBorder` 高级档为渐变 brush 描边；
  真采样只增悬浮条 1 条管线，且仅在高级 + API31+ 时存在。
- **可读性**：底图叠黑 58% + 暗角，正文色 `GlassText`；弹窗/抽屉为背景取色渐变（压暗 0.58、alpha 0.94）+ 0.6 遮罩，列表与输入可读且保留少量背景透色。
- **零回归**：复古玻璃绘制代码已还原为改动前；所有高级分支由 `isAdvancedGlass` 门控。

## 14. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 封面拼贴底图在单色/暗封面下浑浊 | 最多取 6 张封面拼贴提高色彩多样性；压暗 48% + 暗角保证层次；验收抽 3 组不同库 |
| 封面解码失败/库内无封面 | 瓦片保留底色、整张失败返回 null 并退化为主题色软色斑；解码全部 runCatching |
| 底图内存占用 | 288×432 ARGB ≈ 0.5MB，单条缓存；离开高级玻璃时清空（`clearAmbientBackdropCache`） |
| `isGlass` 语义扩大后个别分支对高级玻璃不适用 | §5.2 列出的 16 处调用点逐一 review；色值类补分支，行为类不动 |
| 浅色磨砂膜在亮封面区域文字对比不足 | 底图统一压暗 58% + 暗角；弹窗/抽屉用 80% 不透明度灰玻璃膜 + 0.6 遮罩；必要时单点调 alpha |
| 渐变描边在 Miuix squircle 上错位 | 沿用复古玻璃既有结论（32dp 下不可辨）；异常则描边保持单色 + 仅叠顶边高光 |
| 悬浮条 `drawBackdrop` 在部分 ROM 崩溃（AGSL 探测） | 复用 `GlassShaderSupport` 探测与回退逻辑，失败退回浅色半透膜 |
| 更名影响用户认知 | 仅文案变化：设置页选项、禁用说明、文档；存储/行为不变 |
| 回滚 | 新增值归一化即回默认；高级分支全部由 `isAdvancedGlass` 门控，删除高级文件与两处分发即回到复古/默认两档 |

### 16.4 弹窗/抽屉改为浅玻璃膜（用户反馈）

用户反馈：游戏启动抽屉与统一弹窗的面板是黑的，应使用页面背景。修正：
`AdvancedGlassPanel` 由 85% 深色改为 **20% 白浅玻璃膜**——独立窗口虽然采不到主窗口 backdrop，
但对话框/抽屉窗口本身是透明的，浅膜可直接透出被遮罩压暗的页面背景（与参考图卡片一致的观感）；
配套加深遮罩保证可读性：`AppAlertDialog` 0.7、抽屉 0.7、封面搜索弹窗 0.7、
`GameShortcutCropDialog` 新增 0.7 遮罩、Miuix `windowDimming` 0.7。
抽屉条目由不透明 `AdvancedGlassSurfaceSolid` 改为 `AdvancedGlassSurfaceHigh`（20% 白）；
`AdvancedGlassPanelSolid` 删除（不再需要）。复古玻璃的深色面板保持不变（其页面背景是深色渐变，
深色面板即既有设计）。

### 16.5 面板不透明度回调（用户反馈）

用户反馈：20% 白浅玻璃膜**过于透明**，抽屉/弹窗内容与背景混在一起。修正：
`AdvancedGlassPanel` 改为 **80% 不透明度中性灰（`0xCC4A4E56`）**——保留约 20% 页面背景透色，
但整体足够实，白色正文与次要文字对比回到安全区（面板 ≈ 8:1、面板内条目 ≈ 5:1）；
遮罩相应回到 0.6（不再需要 0.7 补偿）。抽屉条目仍用 `AdvancedGlassSurfaceHigh`（20% 白），
在灰面板上呈略亮的玻璃卡。

### 16.6 面板改为页面背景取色渐变（用户反馈）

用户反馈：不要灰色渲染玻璃，要从页面背景取色做渐变。修正：
删除固定灰色 `AdvancedGlassPanel`，新增 `rememberAdvancedGlassPanelBrush()`（`theme/AdvancedGlassStyle.kt`）——
把环境底图按高度三等分取平均色，向深色基底 `#121418` 压暗 0.58、alpha 0.94 生成竖向渐变；
底图为空时用主题色 + 兜底背景色。四处面板改用该渐变：
`AppAlertDialog` / `GameShortcutCropDialog`（Card 容器透明 + modifier 画渐变）、
封面搜索弹窗（替换原背景色）、游戏启动抽屉（`ModalBottomSheet` 的 modifier 画渐变 + 容器透明，
已核对 Material3 1.4.0 源码：传入 modifier 在 Surface 自身背景之前，含把手区域）。
抽屉条目仍为 `AdvancedGlassSurfaceHigh`（20% 白）。

### 16.7 抽屉底色错位修复（用户反馈截图）

实机截图显示抽屉下半截透出页面、底色画在了屏幕上方。原因：抽屉位置由 Material3 内部
`draggableAnchors` 布局偏移决定，挂在 `ModalBottomSheet` 外层 modifier 的背景会画在**未偏移**的
布局位置（与项目此前「玻璃描边错位」同一个坑）。修正：
- 抽屉取色渐变改画在内容层（`LazyColumn` 的 modifier），随抽屉偏移一起移动；
- 把手条用 `AdvancedGlassPanelSurface.topColor`（渐变顶端色）铺底，与内容层渐变无缝衔接；
- `containerColor` 保持透明；`AdvancedGlassPanelSurface` 由 `rememberAdvancedGlassPanelBrush()` 升级而来
  （返回 brush + topColor），弹窗侧改用 `.brush`。
同时把取色压暗比例由 0.58 提高到 0.68，保证白色正文对比（浅色封面取色后面板不再发白）。

### 16.8 组件玻璃对齐悬浮默认导航条（用户反馈）

用户反馈：界面组件的玻璃效果要与高级玻璃的默认导航栏一致。导航栏材质 = 真采样 blur + vibrancy
+ Highlight + Shadow + 20% 白膜 + 渐变描边；组件侧因处在被录制的内容层内无法再采样自身
（背景已是模糊图，再 blur 也无视觉差异），因此对齐**光学组合**：
- 磨砂膜 `AdvancedGlassSurface` 15% → **20% 白**（与 `AdvancedGlassNavSurface` 同档）；
- 顶边高光折入 `advancedGlassBorder`（原独立 `glassSpecular` 删除），全部 33 处 `glassBorder`
  调用点自动获得导航条同款 Highlight；
- 新增 `Modifier.glassShadow()`（导航条 `Shadow.Default` 的等价实现：BlurMaskFilter + 形状内部挖空），
  挂到全部 MiuixCard/Card 页面卡、快捷启动卡、游戏封面卡、三个弹窗、搜索框与悬浮条降级路径；
  列表行不挂，避免滚动发噪与投影开销；弹窗/抽屉是独立窗口，不接 backdrop 采样（沿用取色渐变面板）。

### 16.9 组件补上导航栏的「受光内描边」（用户反馈）

用户反馈：导航栏有一层描边，组件没有。深入分析后确认导航栏边缘是**两层**叠加：
1. `drawBackdrop(highlight = Highlight.Default)` —— 库的加色受光内描边：白 50%、`BlendMode.Plus`、
   宽度 0.5dp、描边加宽后裁剪到形状内只露内侧一半；API 33+ 走方向性 AGSL shader（45°/falloff），
   31–32 走 BlurMaskFilter 兜底；
2. `.glassBorder()` —— 我们的渐变发丝线 + 顶边高光。

组件此前只有第 2 层：白发丝线是 35%→12% 普通混合，在浅色模糊底图上对比极弱，所以看起来「没有描边」。
组件不能直接复用库的 Highlight（它必须搭 `drawBackdrop` 采样，而组件在被录制的内容层内无法采样自身；
背景又已是模糊图，再 blur 也无视觉差异，只会多出 N 条 RenderEffect 管线）。

修正：在 `advancedGlassBorder` 内等价实现第 1 层——
45° 对角白色渐变（受光侧 50% → 背光侧 10%）、`BlendMode.Plus`、描边宽度 ×2 后 `clipPath` 到形状内
只保留内侧一半（与库 `HighlightNode` 同款做法）。同时给 `glassBorder` 增加 `rim: Boolean = true` 参数，
悬浮默认导航条（已有库 Highlight）传 `rim = false`，避免叠加成双倍亮度。
现在组件与导航栏的边缘组成完全一致：加色受光内描边 + 上亮下暗发丝线 + 顶边高光。

### 16.10 玻璃整体压暗（用户反馈）

用户反馈：组件与导航栏的玻璃偏白，要暗一点。修正（仅调白膜与光学白的不透明度，不改结构）：
`AdvancedGlassSurface` 20% → **14%**、`AdvancedGlassSurfaceHigh` 20% → **18%**、
`AdvancedGlassNavSurface` 20% → **14%**、`AdvancedGlassSpecular` 20% → **12%**、
描边 35%/12% → **30%/8%**、受光内描边 50%/10% → **40%/7%**；
弹窗/抽屉取色面板的压暗比例 0.68 → **0.72**，随组件一起变暗。

### 16.11 描边压暗（用户反馈）

用户反馈：描边也要暗一点。修正：渐变描边 30%/8% → **20%/5%** 白；
加色受光内描边 40%/7% → **30%/5%**。结构不变，仅降白度。

### 16.12 导航栏描边与组件统一（用户反馈）

用户反馈：高级玻璃的默认导航栏描边也要和组件一样（此前导航栏用库的 `Highlight.Default`，
白度固定 50%、比组件的 30%/5% 受光内描边亮一档）。修正：悬浮默认导航条的 `drawBackdrop`
`highlight` 置为 `null`，描边统一走 `glassBorder`（`rim = true` 默认档）——
现在导航栏与页面组件的边缘完全同源：受光内描边 30%/5% + 渐变发丝线 20%/5% + 顶边高光 12%。
附带收益：不再由库构造 `Highlight` 的 AGSL RuntimeShader，少一处 33+ 崩机风险。
