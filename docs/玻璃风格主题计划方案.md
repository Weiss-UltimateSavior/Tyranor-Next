# 玻璃风格主题计划方案

> 目标：在应用设置中新增「外观风格」下拉项（默认 / 玻璃）。玻璃风格下：页面背景固定为黑灰渐变，
> 所有卡片/条目/弹窗/面板变为半透明毛玻璃 + 0.5px 描边；外观模式与色调切换置灰不可用，
> 色调轮盘保持可用。切换即时生效、无需重启，默认风格保持现有视觉完全不变。

---

## 1. 决策记录（已与用户确认）

| 决策点 | 结论 |
|---|---|
| 毛玻璃实现 | **半透明拟态玻璃**：半透明深色玻璃面 + 0.5px 亮边；不逐组件做真采样模糊（背景是纯渐变，视觉差异极小；全 API 兼容、零 blur 管线开销）。底部导航沿用现有 `kyant backdrop` 真模糊 |
| 强调色 | **色调轮盘在玻璃风格下保持可用**，沿用用户已选主题色，不强制默认蓝 |
| 外观模式 | **玻璃风格下禁用**（背景固定黑灰渐变，浅色无意义）；切回默认风格后恢复原值 |
| 背景渐变 | 固定黑灰竖向渐变（建议 `#26282C → #0E0F11`） |
| 描边 | 统一 0.5dp 发丝线（实现见 4.4；如需物理 0.5px 可在单点调整） |
| 计划落档 | 本文档 |

## 2. 现状与改动面

- 主题入口：`theme/Theme.kt`（Material）、`theme/MiuixSettingsTheme.kt`（Miuix）双主题，均从
  `theme/AppThemeColors.kt` 快照读取 primary / isDark / toneSwitch，`@NonSkippableComposable` 保证即时重组。
- 颜色常量：`theme/Color.kt` 的 `PageGrey`（页面背景）/ `NavWhite`（卡片容器）/ `TextColor` /
  `UnselectedGrey` 均为读取快照的 `get()`，全局引用点约 17 个文件。
- 设置存储：`core/settings/AppSettingsStore.kt`（独立 `app_settings` prefs），导航栏样式
  `nav_style` 是现成参照（字符串常量 + get/set + 内存 `StateFlow`）。
- 应用设置页：`ui/settings/AppSettingsActivity.kt:70`，已有语言 / 色调轮盘 / 外观模式 / 色调切换 / 液态玻璃导航五张 MiuixCard。
- 根背景：`MainActivity.kt:65` 的 `Surface(colorScheme.background)` 与 `ui/common/AppScreen.kt:64`
  的 `AppScreenScaffold`（所有二级页宿主）是唯二的根 Surface；`MainScreen.kt:122` 内容层再铺一次背景色。
- 公共容器组件：`AppNavItem`（页面 `NavWhite` / 弹窗内 `PageGrey` 对偶）、`AppAlertDialog`
  （白底 8dp 卡片）、`AppTopBar`（页面背景色顶栏）、`AppSearchField`（Miuix SearchBar，底色取
  `surfaceContainerHigh`）、`GameActionsSheet`（`ModalBottomSheet`，底色取 `colorScheme.background`）。
- Miuix 组件取色全部来自 `MiuixTheme.colorScheme`（Card→`surfaceContainer`、输入框→
  `surfaceContainerHigh`、弹窗遮罩→`windowDimming`、分割线→`dividerLine`），在
  `MiuixSettingsTheme` 内改 scheme 即可批量生效。

## 3. 设置模型

### 3.1 `core/settings/AppSettingsStore.kt`

```kotlin
const val KEY_APPEARANCE_STYLE = "appearance_style"
const val APPEARANCE_STYLE_DEFAULT = "default"
const val APPEARANCE_STYLE_GLASS = "glass"

fun getAppearanceStyle(c: Context): String =
    prefs(c).getString(KEY_APPEARANCE_STYLE, APPEARANCE_STYLE_DEFAULT)
        ?.takeIf { it == APPEARANCE_STYLE_GLASS } ?: APPEARANCE_STYLE_DEFAULT

fun setAppearanceStyle(c: Context, style: String) { /* normalize + putString */ }
```

不新增 StateFlow：UI 统一订阅 `AppThemeColors` 快照（与色调/外观模式同源），避免双状态源。

### 3.2 `theme/AppThemeColors.kt`

```kotlin
var isGlass by mutableStateOf(false); private set

fun refresh(context: Context) {
    isGlass = AppSettingsStore.getAppearanceStyle(context) == AppSettingsStore.APPEARANCE_STYLE_GLASS
    primary = parseColorHex(AppSettingsStore.getThemeColorHex(context))   // 轮盘可用，不强制
    isDark = isGlass || AppSettingsStore.isDarkEffective(context)         // 玻璃恒深色
    toneSwitchEnabled = !isGlass && AppSettingsStore.isToneSwitchEnabled(context)
    // ThemeColorPayload：isGlass 时 darkMode=true、card/text 用玻璃面板色
}
```

- `ensureLoaded` 不动：首帧由两套主题调用 `refresh`，玻璃风格在首帧即生效。
- 设置页切换风格时：`AppSettingsStore.setAppearanceStyle(...)` → `AppThemeColors.refresh(ctx)`，
  全 App 即时重组。

## 4. 视觉体系

### 4.1 色板（新增到 `theme/Color.kt`，随 `isGlass` 取值的动态常量）

```kotlin
// 玻璃专用（仅 isGlass 分支使用）
val GlassBgTop = Color(0xFF24262B)           // 渐变起点（冷灰顶，压暗）
val GlassBgMid = Color(0xFF17191D)           // 渐变中段过渡
val GlassBgBottom = Color(0xFF0A0B0D)        // 渐变终点（近黑）
val GlassBgGlow = Color(0x0AFFFFFF)          // 顶部环境光晕（径向，4% 白）
val GlassSurface = Color(0xCC191B1F)         // 卡片/条目：80% 深色，保证可读
val GlassSurfaceHigh = Color(0xE61F2126)     // 输入框/弹窗内条目：90% 深色
val GlassPanel = Color(0xE6141518)           // 弹窗/抽屉面板：90% 深色
val GlassBorder = Color(0x24FFFFFF)          // 0.5px 描边：14% 白
val GlassText = Color(0xFFEDEEF0)            // 主文字
val GlassTextSecondary = Color(0xFFA6AAB0)   // 次要文字
val GlassUnselected = Color(0xFF7F858D)      // 未选中
```

> 背景最终形态：`GlassBackground` 用 `drawWithCache` 叠两层——三档竖向渐变
> （0f 冷灰顶 / 0.52f 中灰 / 1f 近黑）+ 顶部环境光晕（圆心略高于屏幕顶端、半径约 55% 屏高、
> 4% 白），过渡平滑且顶部不发白；仅做微弱层次，不做提亮。
>
> 面板透明度取舍：初稿的 8%/12% 白在纯渐变上会过度透明（下拉浮层、搜索框无额外底板），
> 最终取 80%~90% 深色半透明，保留渐变透视的同时保证可读。

`PageGrey / NavWhite / TextColor / UnselectedGrey` 增加 `isGlass` 分支：

| 常量 | 默认风格 | 玻璃风格 |
|---|---|---|
| `PageGrey` | 现状 | `Color.Transparent`（露出根部渐变） |
| `NavWhite` | 现状 | `GlassSurface` |
| `TextColor` | 现状 | `GlassText` |
| `UnselectedGrey` | 现状 | `GlassUnselected` |

新增对偶常量 `DialogItemSurface`：默认 = `PageGrey`；玻璃 = `GlassSurfaceHigh`。
用于「弹窗内条目」——玻璃下 `PageGrey` 透明会导致条目在玻璃弹窗上不可见，原
`AppNavItem(containerColor = PageGrey)` 的弹窗调用点改传它。

### 4.2 两套主题的 scheme 映射

`theme/Theme.kt`（Material）：`background/surface = PageGrey`（玻璃下透明）、
`onBackground/onSurface = TextColor` 已具备；补充 `surfaceVariant/outline` 指向玻璃色即可。

`theme/MiuixSettingsTheme.kt`（玻璃分支）：

```kotlin
background = PageGrey                // 透明，露出渐变
surface = PageGrey
surfaceContainer = GlassSurface      // MiuixCard 默认底色 → 全部卡片自动玻璃化
surfaceContainerHigh = GlassSurfaceHigh       // SearchBar/InputField
surfaceContainerHighest = GlassSurfaceHigh
onBackground = onSurface = onSurfaceContainer = TextColor
onSurfaceContainerVariant = GlassTextSecondary
outline = dividerLine = GlassBorder  // 下拉浮层、分割线
windowDimming = Color.Black.copy(alpha = 0.6f)
primary = 存储主题色（轮盘可用）
```

### 4.3 渐变根背景（新增 `theme/GlassStyle.kt`）

```kotlin
@Composable
fun GlassBackground(modifier: Modifier = Modifier, content: @Composable () -> Unit) {
    val modifier = if (AppThemeColors.isGlass)
        modifier.background(Brush.verticalGradient(listOf(GlassBgTop, GlassBgBottom)))
    else modifier else modifier.background(MaterialTheme.colorScheme.background)
    Box(modifier.fillMaxSize()) { content() }
}
```

落地两处根：
- `MainActivity.kt:65`：`Surface` 替换为 `GlassBackground { MainNavigation() }`。
- `ui/common/AppScreen.kt:70`：`Surface` 替换为 `GlassBackground { ... }`（覆盖全部二级页）。
- `MainScreen.kt:122` 保持 `.background(colorScheme.background)`（玻璃下透明），不重复铺渐变。

### 4.4 玻璃描边修饰符（`theme/GlassStyle.kt`）

```kotlin
private val GlassShape = RoundedCornerShape(8.dp)

fun Modifier.glassBorder(
    shape: Shape = GlassShape,
    width: Dp = 0.5.dp,
    color: Color = GlassBorder,
): Modifier = if (AppThemeColors.isGlass)
    border(BorderStroke(width, color), shape) else this
```

- 读取快照 state → 风格切换自动重组。
- 0.5dp 在高密度屏渲染为 1~2 物理像素；若要求物理 0.5px，可单点改为
  `drawWithCache { onDrawWithContent { drawContent(); drawOutline(...) } }` 用 `0.5f` 像素，
  本方案默认 0.5dp（视觉发丝线）。
- MiuixCard 用 squircle 填充、描边用 RoundedCornerShape(8dp)，8dp 半径下差异肉眼不可辨，接受。

## 8. 降级、性能与边界

- **API < 31**：不依赖 RenderEffect，半透明 + 描边完整生效，无模糊损失；`LiquidGlassNavigationBar`
  继续走其 <31 实色分支。
- **性能**：全 App 只多一层渐变 Box 与每组件一条 hairline；无逐组件 blur 管线，滚动/网格无新增开销。
- **无法真采样处（弹窗/抽屉是独立窗口）**：统一用 `GlassPanel` 高不透明度面板，可读性优先。
- **对比度**：文字统一 `GlassText`；封面网格上文字仍在卡片内部；若个别页面出现低对比，单点调 `GlassPanel` alpha。
- **默认风格零回归**：所有玻璃逻辑均由 `isGlass` 门控，`isGlass=false` 时行为与现状逐像素一致。

## 11. 风险与回滚

| 风险 | 缓解 |
|---|---|
| `colorScheme.background` 透明导致某处露出窗口透明 | 根部渐变全覆盖（MainActivity/AppScreenScaffold）；验收时专项检查对话框/输入法场景 |
| 弹窗内条目原先靠 `PageGrey` 与白底反差，玻璃下失效 | 新增 `DialogItemSurface` 统一替换，grep 全部 `PageGrey` 调用点逐个判定 |
| Miuix squircle 与 RoundedCornerShape 描边错位 | 8dp 小半径不可辨；如出现可见偏差，描边改由 `squircleBackground` 叠加或降低描边 alpha |
| 个别存量主题色（低饱和）在玻璃下对比不足 | 轮盘保持可用可自行调整；不做强制替换 |
| 回滚 | 设置仅多一个 prefs key；代码改动全部 `isGlass` 门控，回滚即删除玻璃分支或把默认值锁回 `default` |
