# 审核模板目录说明

本目录用于存放 PR 审核模板，以及分支审计/修复循环的轮次审计报告。

## 收录规则

- 允许的文件（两类）：
  - [PR-REVIEW-TEMPLATE.md](PR-REVIEW-TEMPLATE.md)
  - 分支审计循环的轮次审计报告（命名 `codex-<分支名>-audit-<日期>.md`）：多视角盲审的汇总裁决文档，兼作该分支 P3 遗留项的跨轮次台账；随修复轮以 `docs:` 提交入库
- 禁止放入任何审核或测试过程中的证据与材料，包括但不限于日志、截图、命令输出、测试结果、性能数据、复现步骤记录
- 禁止放入过程记录、草稿、临时文件以及与上述两类无关的内容
- 审核证据应保留在对应 PR 评论、CI 产物或其他既定位置，不进入本目录
- 历史评审证据不存入本目录，文档中只引用 PR/commit URL；不得新增截图、日志或测试输出

## 条款修订说明（2026-11-17）

本目录此前「仅允许模板」的条款与分支审计循环的既定入库惯例冲突：`codex/bangumi-vndb-play-status` 分支的历轮审计报告（R1/R3/R5/R7/R9）曾按循环约定随修复轮以 `docs:` 入库，2026-11-14 文档整理时移至备份分支并收紧为本目录「仅允许模板」。轮次审计报告是分支开发过程的正式裁决文档与遗留项台账（非「PR 评审证据材料」——不含日志/截图/命令输出，遗留项处置需要跨会话可寻、可复核的入库入口），故按 AGENTS.md「文档与实践一致」精神恢复第二类收录并限定命名与用途；除轮次报告外，「禁止评审证据入库」的约束不变。
