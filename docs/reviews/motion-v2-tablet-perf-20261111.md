# 常驻分页与设置页：第一组 release 对照

此轮把分页的命中状态放回各页宿主，在绘制节点内按原次序组合入场和背景景深；保留嵌套褪色层及分批进入的设置内容。手机性能与平板布局分开验收。

同一手机、数据及设置，分别核对两份 release、强制 speed AOT、强停冷启后按相同步骤预热。每场景每包三轮，每轮三次往返。gfxinfo 是整轮统计；Perfetto 的 600 ms 窗口则按动作区分实际显示帧、应用超期和调度等待。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 游戏/引擎切换，整轮卡顿帧 | 8/2150 | 8/2172 |
| 切换，主线程 / 渲染线程 P99 | 2.40 / 6.84 ms | 2.07 / 6.68 ms |
| 切换，已关联显示帧中的晚呈现 | 0/1298 | 0/1298 |
| 设置进退，整轮卡顿帧 | 52/1954 | 43/1940 |
| 进入设置，首布局后八帧主线程 P95 | 6.82 ms | 5.46 ms |
| 返回，最长渲染器停止调用的中位耗时 / 其中主线程睡眠 | 6.14 / 6.07 ms | 6.01 / 5.97 ms |
| 返回，应用超期 token | 1/489 | 3/483 |

设置页进退逐轮卡顿帧为 11→14、25→12、16→17，不能从合计下降推出每轮都更快。返回的最长等待主要在系统侧，未见稳定改善。

与独立绘制参考比较，宽窄视口下 6 个交叉淡化、过冲和反向切换状态的 276,456 个采样像素一致。实机设置页 23 条静止语义与 49,670 个前景掩膜像素一致；游戏页、引擎页掩膜内仍分别有 16、29 个不同像素。录屏中回游戏 417.4→416.6 ms，进引擎 432.7→450.0 ms，进设置 399.5→400.0 ms，返回均为 366.8 ms。动态背景与视频帧相位不同，不能声称整屏逐帧相同。

该轮手机 56 项专项通过。平板的两方向与旋转证据见[覆盖矩阵](motion-v2-tablet-coverage.md)；下一轮在此候选包上再做[交错 A/B 对照](motion-v2-tab-pop-perf-20261111.md)。
