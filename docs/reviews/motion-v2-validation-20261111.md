# 手机：提示交接、浮层与绘制检查

这组记录来自移植前的第一轮手机验证。提示状态由当前窗口持有绘制权；源页的旧动画、旧触摸不能在新提示接管后回写。按住暂停自动关闭，但不会重置 350 ms 的离页计时。多个浮层同时存在时，每一层收回自己的剩余进度。

**功能与画面。** 指定的手机 instrumentation 共 51 项通过；这是一组混合回归，不是 51 项独立的动效验收。动效相关样本包括提示替换、真实 Activity 交接、绘制节点重挂载、封面保存后的窗口释放。进度条先前的尺寸比较把布局和截图取自不同时刻；修正取样后，同一张截图内对照两条进度，64 帧逐通道最大差为 1/255。

实录中，弹窗关闭后回到下层抽屉，再返回游戏页。用未被遮挡的页面控件拟合缩放，旧包和候选包的弹窗均为 0.959、抽屉均为 0.953；一次下拉途中为 0.960，回弹后为 0.953。手机改宽布局后的弹窗约 0.964。这里是离散采样，不是整段动画逐帧等价；调密度的手机也不是实物平板。

**同机 release 对照。** 一台荣耀手机（API 37），两包均做 speed AOT。每场景三轮，每轮三次操作；表中是整轮 gfxinfo 卡顿帧占比。设置进入和退出合计，与下文单次动作的主线程尾耗时不是同一个指标。

| 场景 | 旧包初测 | 旧包复测 | 候选包 |
| --- | ---: | ---: | ---: |
| 抽屉开关 | 0.71% | 0.69% | 0.54%（14/2615） |
| 添加游戏弹窗 | 0.63% | 0.68% | 0.64%（18/2804） |
| 应用设置进退 | 2.72% | 1.85% | 2.66%（50/1882） |
| 游戏与引擎互切 | 0.29% | 0.40% | 0.45%（9/2007） |

进入设置后 600 ms 内的主线程 P99 为 11.33 / 9.81 / 7.87 ms，返回为 12.15 / 11.50 / 11.59 ms（旧初测 / 旧复测 / 候选）。这一轮支持抽屉样本改善，不支持全局流畅度提升。未测 API 26/27 真机的无阴影分支、全主题与大字体组合；后续轮次另见[审查索引](motion-v2-review.md)。
