# 界面动效：审查与验收索引

增强档改变页面、控件和反馈的运动；普通档保留各场景原有转场。审查的重点是：视觉变化能否被打断，离场的内容是否还会响应输入或改写状态，以及返回与旋转之后能否继续原操作。

以下为移植前各轮的记录。共同祖先为 `bc96e32d`，文档整合基于 `345be7a4` 的上游。各轮使用的 debug 测试包、release 包和设备不同；这里没有把任何一轮结果算作新 PR 工作树的构建、CI 或设备验收。

| 复核问题 | 可公开的结果 |
| --- | --- |
| 浮层关闭、窗口交接及视觉等价 | [手机专项与绘制检查](motion-v2-validation-20261111.md)：嵌套弹窗返回原抽屉、下拉回弹、网页首页遮挡；进度条按同一帧对照旧实现。 |
| 宽布局、旋转与状态恢复 | [平板覆盖与图片](motion-v2-tablet-coverage.md)：分类、添加步骤和草稿有实际旋转或专项断言，另列待测入口。 |

此前评审还追踪了以下可单独回归的问题：

- 入场节点换绑或被懒列表复用时应更新观察对象，停用/重挂载不能继承旧条目的半途缩放。拖动跳过入场只影响当前作用域；相邻常驻页尚可见时不应被重播逻辑隐藏。
- 松手后的滑条任务不能抢占新手势；空刻度不能发生索引越界；无障碍调整也要交付完成回调。保留轨道未覆盖部分的刻度。固定标签的指示器要按布局方向定位。
- 抽屉完全离屏后、弹窗关闭提交后、游戏卡删除消散中，不得再启动或重复提交操作。关闭过程中释放输入，普通档裁剪弹窗保留平台退场。覆盖层上方的提示须登记在正确的窗口。
- 数字滚动等字符的实际转场结束，慢速与反向打断时不提前切回整段文字。侧栏推入页面后按实际暂停让位，不用固定超时猜导航已完成。覆盖层重入只交付一次操作。
- 从快捷方式打开的独立确认页同样需要初始化动效环境，参数无效时提前关闭也要按当前档位退场。真实游戏的所有冷启动、授权、在线下载和存档操作并未因此得到设备验收。

复查新改动时，可从 [动效实现规则](../../AGENTS.md#动效与视觉反馈的实现边界强制) 和 [离线门禁覆盖范围](../../tools/motion-boundaries.md) 开始，再按涉及的窗口与交互选设备测试。源码检查不证明运行时观感或性能。
