# 具名动效入口、系统返回与跨窗口提示

这轮在源工作树核对了普通/增强分支、状态身份、手势提交与取消、修饰符顺序和绘制时机。离线门禁用来找绕过入口的实现；它不能证明全部画面逐帧等价。接入规则见 [AGENTS.md](../../AGENTS.md#动效与视觉反馈的实现边界强制)。

## 入口与普通档

- 源树盘点：12 个文件、39 处列表调用归入 `listItemMotion`。游戏库两种网格、最近游戏和游戏目录沿用快速补位，其余保留原布局弹簧；普通档不挂列表动画节点。封面加载另有入口，有原版 300 ms 淡入的场景保留该淡入。
- 主标签和引擎分类共用分页弹簧与景深幅度，分别保留原有 Transition 和 Animatable 驱动。遮罩、触摸放行、状态显隐、越界阻力、裁剪、引导、归档和滤镜排序各归其具名组件；业务页仍负责数据与提交。该轮对 16 个导航文件和默认底栏函数做过修改前后指纹核对。
- 交叉审查发现初版抽取让引擎存储环及解包进度在切到普通档时丢掉未完成的弹簧。最终实现保留运动状态，只在绘制时选用原值或动画值；两组中途切档均有设备用例，不能只查两档的静止图。

## 二级设置返回与根任务

原录屏里，从最近任务恢复到应用设置后，偶见关闭近乎硬切；另一次从根设置页退到桌面，重开却落到首页。系统事件证实后者为应用请求结束原 MainActivity，之后在**同一 PID** 创建新实例，无进程崩溃的证据。

Android 14+ 的二级 Activity 在创建及更换动效档时预注册原关闭 XML，旧平台沿用 finish 后覆盖；没有改窗口时长或插值。根页面在手势开始时记住边缘：左缘即使没有中间进度，提交也打开工具面板；取消或离开前台清除记录。右缘及返回键在 Android 12+ 的桌面根任务中按正常行为退后台。

API 36 模拟器和荣耀 API 37 真机的 release 对照均观察到：基线重开回首页，修正后保留任务、MainActivity 和“设置”标签。荣耀经 speed AOT，取消二级页返回仍在原页，提交则回设置，快速左缘提交打开工具。约 900 ms 后返回的两包实录都能辨出 10 个中间位置。又按原片恢复到关闭约 454 ms 的间隔复验：基线 448/450 ms，交付包 440/444 ms，四次均看到横移。结果支持修正版在这个时序能播放，未稳定复现原包偶发硬切，不能声称根因已证实或硬切已消除。

## 通知身份与 350 ms 边界

`MotionNoticeActivityDeviceTest` 使用真实 Activity 与真实时钟。荣耀 API 37 的 debug + instrumentation 记录中三项均通过：新提示在目标窗口以原 ID 显示；已显示够久的两条提示在推入、返回时均未跟随。源页暂停时，fresh 提示的年龄区间为 **[16,20] ms**，两条负对照分别为 **[460,584] ms**、**[458,535] ms**。这些不是 release 性能样本。

API 36 平板另有两次 fresh 夹具测得 **[173,545] ms**、**[377,623] ms**，均不能证明暂停时年龄严格小于 350 ms；另一次停在测试 Activity 启动，未到提示断言。源树最后调整夹具：先用独立提示证明源宿主能显示，待其自然退场，再在同一主线程回调发出待测提示并立即开始真实导航。仍需验证真实年龄、原身份与目标窗口最终可见，推入/返回的负对照保留。没有该版夹具在平板通过的记录，不能用早先的真机通过替代。

## 验证账目

源树该轮 JVM 2,095 项：2,069 通过、26 跳过；应用 lint 和界面字符串检查通过。动效门禁扫描 325 个 Kotlin 文件，其自身 9 项测试通过。引擎 lint 当时仍有 54 个错误，涉及的 8 个文件与当时上游相同；不据此判定本 PR 的 lint 结果。

API 36 平板初次优先组 20 项通过；受影响组为 **37 通过、4 失败、1 项条件不满足**（离线补丁搜索旋转）。最终包上单独复验：添加 Android 游戏读取失败后重试，以及 Artemis 确认弹窗普通/增强档均通过。普通档曾遇到输入焦点超时，随后模拟器系统服务重启；缺少当时的应用主线程栈，不能判为应用死锁。以上不构成全组一次通过。性能与显示帧只见[上一轮四对 release 对照](motion-v2-tab-pop-perf-20261111.md)，本轮没有独立 A/B 数字。
