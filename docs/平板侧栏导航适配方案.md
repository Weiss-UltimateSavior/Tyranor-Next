# 平板侧栏导航适配方案

> 目标：平板/大窗口（sw600dp 平板或宽度 ≥ 840dp）下，主导航从底部移到侧边；
> 侧栏**按外观风格取该主题「默认导航栏」的形态**（默认 = Material3 侧栏、复古玻璃 = 悬浮玻璃柱、
> 高级玻璃 = 悬浮真玻璃柱）；**液态玻璃 · 经典 / 透镜不参与侧栏适配**，平板下自动落到主题默认形态。
> 底栏形态与小屏行为零回归。

---

## 1. 决策记录

| 决策点 | 结论 |
|---|---|
| 断点 | `isTabletScreen()`（`ui/common/ScreenSize.kt`）：`smallestScreenWidthDp ≥ 600`（平板，含竖屏）或 `screenWidthDp ≥ 840`（大窗口）；不使用 `isWideScreen()`（它含「任何横屏」，横屏手机只有 360–420dp 高，4 项竖排会过挤） |
| 开关 | 应用设置新增「平板侧边栏」开关（`AppSettingsStore.sideRailState`，默认**开**）：`isSideRailLayout() = isTabletScreen() && 开关`；关闭时平板也保持底部导航；内存态 StateFlow，设置页切换即时生效 |
| 侧栏形态 | 按外观风格取「默认导航栏」形态：默认外观 → Material3 `NavigationRail`；复古玻璃 → 悬浮玻璃柱；高级玻璃 → 悬浮真玻璃柱（同款光学：`drawBackdrop` vibrancy/blur + 投影 + 受光内描边） |
| 液态玻璃两档 | **不适配**：平板下不渲染液态底栏，直接落到上述主题默认形态；设置页在平板 + 选到液态档时给出「平板上以侧栏显示」提示 |
| 布局 | `Row { 侧栏, 内容层(weight 1f) }`——侧栏占布局宽度，页面不需要新增侧向留白；`glassNavBottomInset()` 在侧栏模式返回 0 |
| 高级玻璃采样 | 侧栏在内容层之外，采样内容层会因坐标越界采不到东西；MainScreen 单独把**纯背景**（cover 铺满 + 压暗 + 暗角）录进 `railBackdrop`，坐标与窗口同源供侧栏采样 |
| 选中动效 | 抽出 `ui/common/NavigationTabIcon.kt`，底栏与侧栏共用同一套「自下而上填充」图标动画 |
| 系统栏 | 侧栏 slot 使用 `WindowInsets.systemBars.only(Vertical + Start)`（横屏三键导航在侧面，start inset 必须避开） |
| 切换时机 | 由 `LocalConfiguration` 驱动，旋转/分屏即时切换，无需重启 |

## 2. 结构

```
MainScreen
└── Box(fillMaxSize)                      // 外层布局
    ├── [railBackdropActive] Box.fillMaxSize().layerBackdrop(railBackdrop).then(pageBackground)
    │                                      // 仅平板+高级玻璃：录制「纯背景层」供侧栏采样
    └── if (railLayout) Row(fillMaxSize)
        │   ├── AppNavigationRail(...)     // 按外观风格取主题默认形态，占布局宽度
        │   └── Column(weight 1f) { MainTabPages(...) }
        └── else Column(fillMaxSize)       // 底栏形态（现状）
            ├── MainTabPages(...)
            ├── [非玻璃/悬浮] DefaultBottomNavigationBar
            └── Box 叠加：液态经典/透镜底栏、玻璃悬浮默认条
```

- `MainTabPages`：从原 `MainScreen` 抽出的四页常驻组合（`ColumnScope` 扩展，含 `weight(1f)`），
  两种布局共用，保证页面与转场完全一致。
- `isSideRailLayout()` = 设备命中 `isTabletScreen()` **且**「平板侧边栏」开关开启。
- `AppNavigationRail`（`ui/common/AppNavigationRail.kt`）：
  - 默认外观：`NavigationRail` + `NavigationRailItem`（无 ripple、无选中指示器，配色对齐底栏）；
  - 玻璃系：悬浮玻璃柱（宽 64dp、`AppComponentShape`）；复古用 `GlassNavSurface` 实底，
    高级用 `drawBackdrop` 采样 `railBackdrop`（`vibrancy + blur 18dp`，highlight 置空——
    描边统一由 `glassBorder` 的受光内描边绘制，与页面组件同款）+ `glassShadow` + `AdvancedGlassNavSurface`。

## 3. 留白与页面适配

| 项 | 处理 |
|---|---|
| 列表底部留白 | `glassNavBottomInset()` 侧栏模式返回 0（导航在侧边占宽度） |
| 侧向留白 | 不需要：侧栏在 `Row` 中占布局宽度，内容区自动收窄 |
| 顶部栏 | 页面自身 `AppTopBar` 在 Row 内自动收窄，无需改动 |
| 游戏网格列数 | 仍按 `isWideScreen()` 取 6 列（侧栏只占约 88dp）；若真机显示过挤，后续按「可用宽度 − 侧栏宽」重算 |

## 4. 边界与降级

- 横屏手机（sw < 600 且宽 < 840）：保持底栏，行为不变。
- API < 31：侧栏高级玻璃的 `drawBackdrop` 不可用 → 退回 `AdvancedGlassNavSurface` 半透膜 + 描边 + 投影。
- 液态玻璃两档在平板下不渲染（`liquidBottomActive = liquidGlass && !railLayout`），
  透镜的 AGSL 探测与回退逻辑不受影响（仍只在底栏路径生效）。
- 旋转/分屏触发 `LocalConfiguration` 变化 → 侧栏 ↔ 底栏即时切换；切页状态（`selectedIndex`）保留。

## 6. 实机修正

| 问题 | 原因 | 修正 |
|---|---|---|
| 平板下首页顶部三张快捷启动卡不占满宽度 | `QuickLaunchSection` 大屏分支给三卡行设了 `widthIn(max = 900.dp)` 上限并居中，平板（去掉侧栏后可用宽度仍 > 900dp）两侧留空 | 移除 900dp 上限，改 `Modifier.fillMaxWidth()`；卡内封面宽度本就有 99dp 上限、文字列自适应，拉宽不挤压内容 |

## 7. 平板侧边栏开关（用户反馈）

用户要求：平板侧栏加设置开关，仅在启用时变侧栏，关闭保持底部，默认开。
- 存储：`AppSettingsStore.KEY_SIDE_RAIL`（默认 `true`）+ `sideRailState` 内存态（设置页切换后主界面即时重组）；
- 判定：`isSideRailLayout() = isTabletScreen() && sideRailState`——主界面布局、`glassNavBottomInset()`、
  设置页的「平板上以侧栏显示」提示共用同一判定；
- 设置项：应用设置页「平板侧边栏」开关（`settings_side_rail` + `settings_side_rail_summary`，三语言），
  放在导航栏样式卡之后；
- 初始化：主界面与设置页各自 `initSideRail(ctx)`（进程重建直接进设置页时开关显示磁盘真值）。
